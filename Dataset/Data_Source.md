- **Name:** Dubai Real Estate: Sales, Off-Plan & Rentals (2020–2026)
- **Creator:** Kaggle user `sergionefedov`
- **Source:** https://www.kaggle.com/datasets/sergionefedov/dubai-real-estate-sales-and-rentals-20202026

| `rentals` | Rental listing-level fact data | 25,000 |

| `area_price_monthly` | Community-by-month price data | 6,384 |
| `metro_stations` | Metro-station reference data | 55 |

## Usage statement

The source contains realistically calibrated, modelled listing-level data with real geographic and market anchors. It is suitable for a portfolio demonstration, but the results must not be represented as official Dubai Land Department transactions or verified market statistics.

The Power Query transformations, dimensional model, DAX measures, report design, analytical interpretation and documentation were developed independently for this portfolio project.
